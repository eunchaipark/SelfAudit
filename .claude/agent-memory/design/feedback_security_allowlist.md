보안 결정은 허용하는 꼴(allowlist)이나 입력 좁히기로 쓰고, 검증이 낼 법한 우회 꼴을 시제품으로 재 본 뒤 그 측정을 결정기록에 예시로 붙인다.

**Why:** 2026-11-20 D-030(취약 목록 정규식)을 막을 꼴 나열(denylist)로 냈다가 총괄이 반려했다. security-reviewer가 우회 꼴 다섯 가지(지수·제곱·세제곱)를 바로 찾아 쟀다.

**How to apply:** 상한이나 거르기를 정할 때는 '최악 비용 = 식' 꼴로 보장을 적는다. 시간 상한보다 개수 상한을 쓴다(NFR-04, 같은 입력이면 같은 결과). 확정된 것과 대리 결정 대상은 커밋을 나눠, 총괄이 앞부분만 병합할 수 있게 한다.
