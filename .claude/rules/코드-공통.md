# 코드 공통 (코드 파일을 열면 자동으로 읽힌다)

전체 기준과 이유는 `docs/코드규칙.md`. 형식·import 순서·타입은 도구가 잡으니 신경 쓰지 말고 `python ops/scripts/check.py`를 돌린다.

- **본보기 기능의 모양을 따른다** (위치는 `docs/00_지도.md`). 새 모양이 필요하면 만들지 말고 요청한다.
- 코드규칙 2장 표에 없는 폴더·모듈은 만들지 않는다. 요청한다.
- 서비스·엔진 함수의 문서 문자열 첫 줄에 기능 ID: `"""F-A01 순자산 (FR-101)."""`
- 식별자는 영어, 주석·문구는 한국어. 주석은 "왜"만.
- TODO에는 기능 ID: `# TODO(F-B08): …`
- 매직 넘버 금지: 기준값은 설정, 상수는 이름 있는 상수.
- 함수는 작게, 하나의 일. 이른 반환으로 중첩을 줄인다.
- 파일은 항상 `encoding="utf-8"`로 연다.
- 현재 시각·난수는 주입받는다. 시간대를 명시한다.
- 죽은 코드·주석 처리한 코드는 남기지 않는다.
- 명세에 없는 동작을 만들지 않는다. 명세가 정하지 않은 작은 부분은 배정문의 목적에 맞게 고르고, 보고서에 적는다.
