# 화면 코드 (화면 파일을 열면 자동으로 읽힌다)

전체 기준은 `docs/코드규칙.md` 5장, 문구와 배치는 화면정의(SCR-…)가 기준이다.

- 영역 화면은 `features/<영역>/`에. 공통 구성 요소(`components/`)는 고치지 않고 요청한다.
- API 타입은 스키마에서 생성한 것만 쓴다. 같은 타입을 손으로 다시 만들지 않는다.
- 서버 상태는 정해진 데이터 훅으로만 가져온다. 서버가 하는 계산을 화면에서 다시 만들지 않는다.
- 색·간격·글꼴은 디자인 토큰만. 구성 요소에 색 코드를 직접 쓰지 않는다.
- 화면 문구는 화면정의에 적힌 그대로. 없으면 지어내지 말고 요청한다.
- 진짜 `<button>`, `<a href>`, `<label>`. 누르는 영역 44px 이상, 글자 대비 4.5:1 이상.
- 외부 텍스트는 일반 텍스트로만. `dangerouslySetInnerHTML` 금지(eslint가 막는다). 외부 링크는 `http`/`https`만, `rel="noopener noreferrer"`.
- 숫자·날짜 표시는 `lib/format.ts`의 함수로만.
