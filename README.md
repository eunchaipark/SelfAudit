# SelfAudit — Claude Code 사용량 분석기

내 PC의 Claude Code 대화 기록을 읽어 **토큰이 어떤 일에 갔고, 그 결과 무엇이 완성됐나**를 보여 준다.
예: "이번 주 토큰의 35%가 코드 만들기, 18%가 검토, 16%가 문서 맞추기 — 커밋 130개 중 60개가 정리 커밋".

왜: 2026-11 앞 판(REA 실험)에서 토큰을 많이 썼는데 무엇이 완성됐는지 보이지 않았다. 그때 손으로 한 분석을 도구로 만든다.
비슷한 도구(ccusage 등)는 일·세션별 합계를 보여 준다. 이 도구는 **에이전트·작업 종류별로 나누고 git 커밋(결과)과 잇는 것**이 다르다.

## 단계
1. **명령줄 도구**: `~/.claude/projects/**/*.jsonl`(하위 에이전트 기록 포함)에서 사용량만 읽어 표로 — 프로젝트·세션·날짜·에이전트별 입력·출력·캐시 쓰기·캐시 읽기 토큰. 같은 `message.id`는 한 번만 센다.
2. **보고서 한 장**: 같은 숫자를 그래프가 든 HTML 한 파일로(서버 없음).
3. **결과와 잇기**: 같은 시간대의 git 커밋 수·바뀐 줄과 나란히 — "토큰 대비 완성된 것".

## 지키는 것
- 대화 본문은 읽어도 옮기지 않는다. 출력·저장소에는 숫자·이름·시각만 남긴다(기록에는 내 코드·경로가 들어 있다).
- 시험은 가짜 기록 파일로만 한다. 진짜 기록은 저장소에 넣지 않는다.
- 표준 라이브러리로 시작한다(Python 3.13, uv).

앞 판 전체는 태그 `archive/before-reset-1128`에 있다. 저장소 밖 `.tools/`(휴대용 Node·REA)는 남아 있다.
