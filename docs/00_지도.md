# 프로젝트 지도 (세션 시작용 · 200줄 이하)

새 세션은 이 파일 하나로 프로젝트를 파악한다. 설계가 관리하고, '현황' 칸만 기록이 고친다.
폴더를 둘러보거나 문서 전체를 읽기 전에 여기부터 본다.

## 한 줄
내 앱의 빌드 결과물(웹 번들·Electron 앱·APK)을 공격자 시점에서 스스로 점검하고, 고친 뒤 전후를 비교하는 보안 자가진단 도구. 같은 분석 엔진으로 문서 없는 코드를 이해하는 리포트는 그다음에 붙인다. 개발자 취업용 포트폴리오 프로젝트

## 폴더
| 폴더 | 용도 | 고칠 수 있는 역할 |
|---|---|---|
| `backend/app/<영역>/` | 영역별 서버 코드 | 그 영역 레인 |
| `frontend/src/features/<영역>/` | 영역별 화면 | 그 영역 레인 |
| `backend/app/core/`, `frontend/src/app/` | 공통 (라우터, 메뉴, 설정, 공통 컴포넌트) | 설계 |
| `backend/tests/` | 서버 테스트 (영역별 하위 폴더) | 그 영역 레인 |
| `docs/` | 명세·기록 / 규칙 | 명세·기록은 문서, 규칙(코드규칙·보안규칙)은 설계 |
| `docs/변경/` | 변경 요청(CR) | 문서 ('기술 검토' 칸만 설계) |
| `ops/` | 운영 파일 | 아래 '파일 주인' 표 |

## 레인
| 레인 | 고칠 수 있는 폴더 | 명세 ID |
|---|---|---|
| <예: 돈> | `backend/app/money/**`, `frontend/src/features/money/**`, `backend/tests/money/**` | F-A, SCR-05 |
| 공통 | 설계가 직접, 또는 영역 '공통' 태스크로 | - |

## 공통 파일 (설계만 고친다)
- 라우터·메뉴, 공통 컴포넌트, 설정 로더
- 의존성 목록과 lock 파일 (`package.json`, `pnpm-lock.yaml`, `pyproject.toml`, `uv.lock` 등)
- DB 마이그레이션 (한 번에 한 태스크만 만든다)
- 생성 파일 (API 스키마에서 만든 타입 등 — 병합 뒤 검증이 다시 만든다)

## 파일 주인
| 파일 | 주인 |
|---|---|
| `.taskmaster/tasks/tasks.json` | 관제 |
| `ops/보드.md` | 총괄 |
| docs 명세(요구사항·기능명세·화면정의·목업)와 그 변경 이력, `docs/README.md`, `docs/문서규칙.md`, `docs/결정기록.md`, `docs/변경/`, `.claude/rules/명세작성.md`, 이 지도의 '현황', `ops/측정.csv` | 문서 |
| `CLAUDE.md`, `docs/코드규칙.md`, `docs/보안규칙.md`, `.claude/`(명세작성 규칙 제외), `ops/checks.json`, 도구 설정 파일, 이 지도('현황' 제외), 공통 파일 | 설계 |
| `ops/보고/`, `ops/인계/` | 그 보고·인계를 쓴 세션 |
| `ops/회고/<역할>.md` | 그 역할 (문제와 개선 한 줄씩) |
| `ops/모델표.md` | 총괄 (바꿀 때는 사용자 확인) |
| `docs/회고.md` | 자동 생성 (`retro.py`). 손으로 고치지 않는다 |
| `ops/검증/`, `verify/*` 브랜치 | 검증 |
| main 브랜치 이동 | 총괄 |

## 명령
| 무엇 | 명령 |
|---|---|
| 검사 전체 | `python ops/scripts/check.py` |
| 검사 하나 | `python ops/scripts/check.py --only <이름>` |
| 병렬 판단 | `python ops/scripts/tm_parallel.py` |
| ID 영향 찾기 | `python ops/scripts/impact.py <ID…>` |
| 새 기능 번호 | `python ops/scripts/impact.py --next <접두어>` |
| 문제와 개선 모으기 | `python ops/scripts/retro.py` → `docs/회고.md` |
| 훅이 도는지 | `.ops-logs/hooks.log` (편집할 때마다 한 줄) |
| 실행 | <예: docker compose up -d --build app> |
| 화면 확인 폭 | <예: 1360 · 768 · 390px> |
| 레인별 포트·DB | <예: 레인마다 다르게 쓸 때만 적는다> |
