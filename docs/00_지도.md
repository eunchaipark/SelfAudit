# 프로젝트 지도 (세션 시작용 · 200줄 이하)

새 세션은 이 파일 하나로 프로젝트를 파악한다. 설계가 관리하고, '현황' 칸만 기록이 고친다.
폴더를 둘러보거나 문서 전체를 읽기 전에 여기부터 본다.

## 한 줄
내 앱의 빌드 결과물(웹 번들·Electron 앱·APK)을 공격자 시점에서 스스로 점검하고, 고친 뒤 전후를 비교하는 보안 자가진단 도구. 같은 분석 엔진으로 문서 없는 코드를 이해하는 리포트는 그다음에 붙인다. 개발자 취업용 포트폴리오 프로젝트

## 기술
| 층 | 쓰는 것 |
|---|---|
| 서버 | Python 3.13, FastAPI, SQLAlchemy 2, Alembic, uvicorn (uv로 관리, `backend/`) |
| 화면 | React 19, TypeScript 5.9, Vite, TanStack Query, React Router (npm, `frontend/`) |
| DB | SQLite `<데이터 폴더>/selfaudit.db` |
| 데이터 폴더 | `%LOCALAPPDATA%\SelfAudit` (바꾸려면 `SELFAUDIT_DATA_DIR`). DB, 로컬 키, `work/`, `uploads/`, `vulndb/` |
| 실행 | 본인 PC, `127.0.0.1:8790`(서버가 빌드된 화면도 준다). 외부 요청 없음 |
| 계약 | `backend/app/contracts/` (엔진 타입·API 스키마) → `backend/openapi.json` → `frontend/src/api/schema.d.ts` |

| 폴더 | 용도 | 고칠 수 있는 역할 |

| `frontend/src/features/<영역>/` | 영역별 화면·데이터 훅 | 그 영역 레인 |

| `frontend/src/app/`, `components/`, `api/`, `lib/` | 화면 공통 (경로표, 틀, 토큰, API 클라이언트, 표시 함수) | 설계 |

| 공통 (`design`) | 공통 파일 (아래) | - | - |

- 레인은 에이전트로 띄운다. 에이전트마다 자기 worktree(`.claude/worktrees/`)와 기능 메모(`.claude/agent-memory/lane-<레인>/`)가 있다. 정의는 `.claude/agents/lane-*.md`.
- 앞의 네 레인은 서로 기다리지 않는다: 주고받는 타입은 `backend/app/contracts/engine.py`, API는 `contracts/schemas.py`에 이미 있다.
- 점검 흐름 레인은 `main.py`의 `TODO(F-I01)` 자리(시작 정리)를 요청으로 설계에 넘긴다(공통 파일).
- 화면 경로(`frontend/src/app/App.tsx`)는 이미 각 레인의 화면 파일을 가리킨다. 레인은 자기 화면 파일만 채운다.

## 명령
| 무엇 | 명령 |
|---|---|
| 처음 한 번 | `cd backend; uv sync` · `cd frontend; npm ci` |
| 검사 전체 | `python ops/scripts/check.py` |
| 검사 하나 | `python ops/scripts/check.py --only <이름>` (서버린트·서버형식·서버타입·서버테스트·계약·화면계약·화면린트·화면타입·화면테스트·빌드) |
| 서버 테스트 하나 | `cd backend; uv run pytest tests/<영역> -q` |
| 계약 다시 만들기 | `cd backend; uv run python -m app.contracts.export_openapi` → `cd frontend; npm run gen:api` |
| 병렬 판단 | `python ops/scripts/tm_parallel.py` |
| ID 영향 찾기 | `python ops/scripts/impact.py <ID…>` |
| 새 기능 번호 | `python ops/scripts/impact.py --next <접두어>` |
| 문제와 개선 모으기 | `python ops/scripts/retro.py` → `docs/회고.md` |
| 훅이 도는지 | `.ops-logs/hooks.log` (편집할 때마다 한 줄) |
| 실행 (빌드된 화면) | `cd frontend; npm run build` → `cd backend; uv run python -m app` → http://127.0.0.1:8790 |
| 실행 (화면 개발) | `cd backend; uv run python -m app --dev` + `cd frontend; npm run dev` → http://127.0.0.1:5173 |
| 화면 확인 폭 | 1360 · 768 · 390px |
| 레인별 포트·DB | 동시에 서버를 띄울 때만 `SELFAUDIT_PORT`, `SELFAUDIT_DATA_DIR`를 레인마다 다르게 |
