# 프로젝트 지도 (세션 시작용 · 200줄 이하)

새 세션은 이 파일 하나로 프로젝트를 파악한다. 설계가 관리하고, '현황' 칸만 기록이 고친다.
폴더를 둘러보거나 문서 전체를 읽기 전에 여기부터 본다.

## 한 줄
같은 Claude Code가 웹 빌드 결과물을 보안 점검할 때 REA(역설계 도구)를 쥐여 주면 더 많이·더 정확히 찾는지(질문 1), 그 실험 도구를 만든 병렬 작업 방식이 한 세션보다 효율적인지(질문 2)를 숫자로 재는 실험 프로젝트(D-035). 옛 보안 자가진단 앱(`backend/`·`frontend/`)은 멈췄다. 개발자 취업용 포트폴리오 프로젝트

## 기술
| 층 | 쓰는 것 |
|---|---|
| 실험 도구 | Python 3.13 표준 라이브러리만(실행 의존성 없음), uv 프로젝트 `bench/` — 개발 도구는 backend와 같은 버전의 ruff·mypy·pytest·pytest-socket (`docs/설계/실험구조.md` 1절, `bench/README.md`). import는 `bench/` 기준(`from common.contracts import …`) |
