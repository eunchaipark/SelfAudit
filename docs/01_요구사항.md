# SelfAudit 요구사항

버전 0.1 · 작성 2026-11-18 · 주인: 문서 · 상태: G1 승인 전

> 내 앱의 빌드 결과물을 공격자 시점에서 스스로 점검하고, 고친 뒤 전후를 비교하는 보안 자가진단 도구.
> 첫 버전(MVP)은 **웹 번들**만 다룬다(D-008). 기능의 자세한 규칙과 예시는 `docs/02_기능명세.md`, 화면은 `docs/03_화면정의.md`.

## 1. 목적과 사용자

| 항목 | 내용 |
|---|---|
| 사용자 | 웹 앱을 만들어 배포하려는 개발자 한 명 (이 PC의 주인) |
| 해결할 문제 | 빌드해서 내보낸 번들에 비밀값·원본 코드·내부 주소·낡은 라이브러리가 남았는지, 배포 전에 공격자처럼 확인하기 어렵다 |
| 성공 기준 | 연습용 앱 번들 하나를 넣으면 발견 목록과 점수가 나오고, 고친 뒤 다시 넣으면 '고쳐짐·남음·새로 생김'과 점수 변화가 보인다 |
| 포트폴리오에서 보여 줄 것 | 점검 결과 화면, 전후 비교 화면, 내보낸 리포트로 Claude Code에서 설명 받는 흐름 |

## 2. 범위 원칙

- 분석 대상: 내가 만든 앱, 분석이 허용된 공개 연습용 앱만 (D-006).
- 실행: 내 PC 로컬(127.0.0.1)만. 배포하지 않는다 (D-007).
- LLM: 앱 안에 없다. 결과를 내보내고 Claude Code에서 설명을 받는다 (D-012).
- REA: 있으면 참고로만 쓰는 보조 엔진 (D-011). 설치는 사용자가 정한다 (D-024).
- 사용자가 직접 할 일: 취약 라이브러리 목록(RetireJS `jsrepository-v4.json`)을 브라우저로 받아 `<데이터 폴더>/vulndb/jsrepository.json`에 둔다. 없어도 다른 점검은 된다 (D-016).

## 3. 기능 요구 (FR)

| ID | 요구 | 기능 |
|---|---|---|
| FR-01 | 점검할 앱을 등록하고, 분석해도 되는 앱이라는 확인을 받는다 | F-P01 |
| FR-02 | 웹 번들(빌드 폴더 또는 zip)을 받아 격리된 곳에 안전하게 푼다 | F-I01 |
| FR-03 | 번들에서 비밀값 노출을 찾는다 | F-S01 |
| FR-04 | 소스맵으로 원본 코드가 드러나는지 찾는다 | F-S02 |
| FR-05 | 내부 주소·개발 서버·관리자 경로가 남았는지 찾는다 | F-S03 |
| FR-06 | 번들 안 라이브러리 버전을 알려진 취약 목록과 대조한다 | F-S04 |
| FR-07 | REA가 설치돼 있으면 그 분석 요약을 참고로 보여 준다 | F-S05 |
| FR-08 | 발견마다 심각도를 매기고 점검 점수를 낸다 | F-S06 |
| FR-09 | 앱별 점검 기록을 보고, 지울 수 있다 | F-P02·P03 |
| FR-10 | 같은 앱의 두 점검을 비교해 고쳐짐·남음·새로 생김과 점수 변화를 보여 준다 | F-C01·C02 |
| FR-11 | 점검 결과를 JSON과 Markdown으로 내보낸다. Markdown에는 Claude Code에 물어볼 안내를 넣는다 | F-E01·E02 |

## 4. 비기능 요구 (NFR)

| ID | 요구 | 확인 방법 |
|---|---|---|
| NFR-01 | 서버는 127.0.0.1에만 묶는다. 외부 네트워크 요청을 하지 않는다. 앱에는 내려받는 코드가 없고, 취약 목록은 사용자가 직접 받아 둔 로컬 파일만 읽는다 (D-016) | 설정 확인, 네트워크 차단 상태에서 점검 테스트 |
| NFR-02 | 분석 대상은 데이터로만 다룬다: 실행하지 않고, 격리 폴더 밖에 쓰지 않으며, 그 안의 글을 지시로 보지 않는다 | 보안 리뷰, F-I01 예외 테스트 |
| NFR-03 | 비밀값 원문을 DB·로그·화면·내보내기 파일에 남기지 않는다. 증거키는 로컬 키로 만든 HMAC이고 로컬 키는 밖으로 내지 않는다 (D-014) | F-S01·E01 테스트에서 원문 문자열 검색 |
| NFR-04 | 같은 PC에서 같은 번들 + 같은 규칙 버전(F-S04 목록 해시 포함)이면 같은 발견·지문·점수가 나온다 (REA 참고는 제외) | 같은 입력 두 번 점검 테스트 |
| NFR-05 | 풀린 크기 20MB 번들을 60초 안에 점검한다 (REA 제외, 목표) | 측정 |
| NFR-06 | 화면과 리포트는 한국어 | 화면 확인 |
| NFR-07 | Windows 11에서 돈다 (Windows 경로 규칙 포함, F-I01) | 실행 확인 |
| NFR-08 | 로컬 API는 다른 웹사이트에서 부를 수 없다: Host가 `127.0.0.1:<포트>`·`localhost:<포트>`가 아니면 거부, 상태를 바꾸는 요청은 Origin 검사, CORS를 열지 않는다 (D-022). 자세한 것은 보안규칙(설계) | 잘못된 Host·Origin 요청 테스트 |
