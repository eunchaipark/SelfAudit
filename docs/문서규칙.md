## 1. 문서 사슬과 ID

`요구사항 → 기능명세 → 화면정의 + 목업 → 태스크`. 앞 문서가 바뀌면 뒤 문서를 고친다.

| 문서 | ID | 예 |
|---|---|---|
| 요구사항 | `FR-` (기능 요구), `NFR-` (비기능) | FR-101, NFR-03 |
| 기능명세 | `F-<영역 글자><두 자리>` | F-A01 (A = 자산) |
| 화면정의 | `SCR-<두 자리>`, 화면 요소 `<화면>-<두 자리>` | SCR-05, 05-07 |
| 공통 구성 요소 | `CMP-<이름>` | CMP-NAV |
| 변경 요청 | `CR-<세 자리>` | CR-007 |
| 결정 | `D-<세 자리>` | D-012 |

- 새 번호는 `python ops/scripts/impact.py --next <접두어>`로 정한다(CR·D는 `--width 3`). 손으로 정하지 않는다.
- 번호는 다시 매기지 않는다. 지운 기능은 요구사항 '보류 목록'으로 옮겨 번호를 남긴다.
- 범위 표기는 `F-A01~A05`, 여러 개는 `F-A10·A11`. (`impact.py`가 이 표기를 알아본다)
- 예시 ID만 들어 있는 규칙·양식 문서는 둘째 줄에 `<!-- impact: 건너뜀 -->`를 둔다. 그래야 `impact.py`가 예시를 실제 기능으로 세지 않는다.

## 2. 기능 절 형식 (기능명세)

기능 하나 = 절 하나. 절 제목은 **ID로 시작**한다(`impact.py`가 이 줄을 '정의'로 본다). 그 절만 읽어도 만들 수 있게 쓴다.

```
### F-A01 순자산 (FR-101)

| 항목 | 내용 |
|---|---|
| 입력 | 계좌별 잔액(원, 0 이상 정수), 기준일 |
| 처리 규칙 | 1. … 2. … (번호를 붙여 차례대로) |
| 출력 | 순자산(원), 계좌별 비중(%, 합 100) |
| 예외 | 잔액 없음 → '0원'과 안내 / 기준일이 미래 → 거부 |
| 화면 | SCR-02 02-01 |

**예시** (숫자는 가상)
| 입력 | 출력 |
|---|---|
| 잔액 30,000,000 + 8,420,000 | 순자산 38,420,000, 비중 78.1% · 21.9% |
| 잔액 없음 | 0원 |

미결: (없으면 줄을 지운다)
```

## 3. 예시 쓰는 법 (테스트가 된다)

- **숫자로** 쓴다. "적당히", "많으면" 같은 말은 테스트가 될 수 없다.
- 평범한 경우 1개 + 경계값 1~2개(0, 최대, 빈 값, 날짜 경계).
- 반올림·단위·정렬 순서처럼 결과가 갈리는 규칙을 적는다.
- 계산 예시는 **직접 계산해서 확인**한다(파이썬으로 한 번 돌려 본다).
- 예시의 숫자는 가상임을 밝힌다. 실제 개인 값을 쓰지 않는다.

## 4. 문장 규칙

- 쉬운 말, 짧은 문장, 표. 근거가 되는 ID를 연결한다.
- 단정하지 않는다: "추천" 대신 "후보", 인과 대신 "가능 요인", 예측 대신 "가정에 따른 계산".
- 화면 문구는 화면정의에 실제 문구 그대로 적는다(레인이 지어내지 않게).
- 정하지 못한 것은 `미결:`로 적고 결정기록에 올린다. 레인은 미결이 있는 기능을 시작하지 않는다.

## 5. 변경 이력과 버전

- 문서마다 맨 끝에 변경 이력 표: `| 버전 | 날짜 | 내용 |`.
- **버전 번호는 사용자가 원할 때만 올린다.** 그 밖에는 `(버전 유지)`로 적는다.
- 변경 요청으로 바뀐 절은 끝에 `(CR-<번호>)`를 붙이고, 변경 이력에도 CR 번호를 적는다.
- 명세 문서의 변경 이력에는 **명세 내용이 바뀐 것만** 적는다. 구현이 끝난 기록은 `docs/README.md` 태스크 표와 CR에 남긴다.

## 6. 변경 요청과 결정

- 변경 요청은 `ops/양식/변경요청.md` 양식으로 `docs/변경/CR-<번호>.md`. '원래 말'에는 사용자 말을 그대로 옮긴다(바꿔 쓰지 않는다).
- 결정기록은 한 줄에 하나: 날짜, 결정, 이유, 영향, 상태. CR에서 나온 결정은 CR 번호를 같이.

## 7. 목업과 화면정의

- 화면정의가 기준이고 목업은 그림이다. 둘이 다르면 화면정의를 따르고, 목업을 고친다.
- 목업의 숫자는 모두 예시이고, 그렇다고 표시한다.
