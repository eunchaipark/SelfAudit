## 무엇을, 왜
실행 폴더가 홈 아래(`%LOCALAPPDATA%`)라 위쪽에 사용자의 `~/.claude`가 있어, 명세대로 만든 확인 ㉢이 이 PC의 모든 배치를 멈췄다(T30). 총괄이 대리로 자리를 홈 밖으로 옮겼고(D-048), 설계가 그에 따른 맨 위 권한·㉢ 넓히기·내 앱 지문 칸·가림 꼬리 경계를 정해 코드와 시험까지 고쳐 병합했다(8.9).
명세는 아직 옛 자리와 옛 가림 규칙을 말한다. 그대로 두면 T32·T34 레인이 명세와 코드 가운데 어느 쪽을 따를지 모른다. 그래서 8.9의 옮길 줄과, 검토·보고서가 짚은 '명세에 없는데 만든 것'을 명세에 옮긴다. 새로 고른 값은 (1)의 자리뿐이고 그것도 이미 총괄이 정했다.
'지금' 칸은 main d0e46fd의 명세 글이다. 예시는 코드(`bench/run/store.py`·`bench/score/match.py`)를 직접 돌려 확인했다(아래 '예시').
