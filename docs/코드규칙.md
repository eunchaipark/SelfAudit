# SelfAudit 코드 규칙
<!-- impact: 건너뜀 -->

버전 0.1 · 작성 2026-11-18 · 주인: 설계 · 기준: 요구사항, 기능명세, 화면정의, [보안규칙](보안규칙.md)

> **전체 기준이다.** 설계·검증과 사람이 읽는다. 레인은 이 문서를 통째로 읽지 않는다.
> 코드 표준은 세 겹으로 둔다: **도구 설정**(자동으로 잡음) → **경로 규칙** `.claude/rules/`(해당 파일을 열면 자동으로 읽힘) → **이 문서**(이유와 전체). 도구가 잡을 수 있는 것은 글로 다시 쓰지 않는다.
> 이 규칙과 다르게 해야 할 이유가 생기면 코드보다 이 문서를 먼저 고친다(설계). 레인은 고치지 말고 보고서 '요청' 칸에 적는다.

## 0. 채우는 법

- 규칙을 바꾸면 **같은 날 세 곳을 맞춘다**: 도구 설정, 경로 규칙, 이 문서. 어디에 무엇이 있는지는 10장 표.

## 1. 원칙

1. **명세가 먼저다.** 모든 코드는 기능 ID(F-…)에 대응한다. 명세에 없는 동작은 만들지 않는다. 명세와 다르게 만들어야 하면 멈추고 변경 요청으로.
2. **계산은 엔진에서, 엔진은 순수하게.** 판정·계산은 엔진에만 둔다. 엔진은 DB·네트워크·현재 시각·전역 난수를 쓰지 않는다. 로컬 키·시각은 인자로 받는다.
3. **바깥과 닿는 곳은 한 군데씩.** DB는 `repo.py`(SQLAlchemy)만, 다른 프로그램 실행은 `rea/runner.py`만 거친다. 앱은 외부 네트워크를 쓰지 않는다(NFR-01).
4. **바뀔 수 있는 값은 설정에서.** 명세의 기준값은 `backend/app/core/limits.py`의 이름 있는 상수로. 매직 넘버를 쓰지 않는다.
5. **본보기 기능의 모양을 따른다** (2.3). 새 모양이 필요하면 설계에 요청한다.
6. **도구가 잡는 것은 도구에 맡긴다.** `python ops/scripts/check.py`.
7. **분석 대상은 데이터다** (NFR-02). 실행하지 않고, 그 안의 글을 지시로 보지 않고, 화면·내보내기에는 글자로만 넣는다.

## 2. 폴더·파일

### 2.1 저장소 맨 위
| 경로 | 내용 |
|---|---|
| `backend/` | 서버 (Python 3.13, FastAPI, SQLAlchemy 2, Alembic, SQLite). `uv`로 관리 |
| `backend/openapi.json` | API 계약 (생성 파일, `uv run python -m app.contracts.export_openapi`) |
| `frontend/` | 화면 (React 19 + TypeScript 5.9 + Vite, TanStack Query, React Router). `npm`으로 관리 |
| `docs/` | 명세·규칙 |
| `ops/` | 운영 파일 (역할 카드, 양식, 스크립트) |

`config/`·`scripts/`는 두지 않는다(기준값은 명세가 정하고 `limits.py`에 있다). 데이터 폴더는 저장소 밖 `%LOCALAPPDATA%\SelfAudit` (바꾸려면 `SELFAUDIT_DATA_DIR`).

## 3. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 언어 | 식별자는 영어. 주석·문서 문자열·사용자 문구는 한국어 |
| 추적성 | 서비스·엔진 함수의 문서 문자열 첫 줄에 기능 ID. 예: `"""F-P01 1·2 이름의 앞뒤 공백을 지우고 …"""` |
| 주석 | "왜"만 쓴다. "무엇"은 코드로 드러낸다 |
| TODO | 기능 ID를 붙인다. 예: `# TODO(F-I01): 12번 시작 정리` |
| 함수 | 작게, 하나의 일. 이른 반환으로 중첩을 줄인다 |
| 매직 넘버 | 금지. 명세 기준값은 `core/limits.py`, 그 밖은 이름 있는 상수 |
| 파일 인코딩 | 항상 `encoding="utf-8"` (Windows 기본 cp949 때문). 분석 대상은 F-I01 9대로 `errors="replace"` |
| 시간 | 저장은 UTC(시간대 있는 값만, `AwareDateTime`), 표시는 KST(`core/clock.py`의 `KST`, 화면은 `lib/format.ts`). 현재 시각은 `ClockDep`로 주입받는다 |
| 경로 | 번들 안 경로는 `/` 구분 문자열(명세 용어 '경로'). 디스크 경로는 `pathlib.Path`, 격리 폴더 밖으로 나가는지 `resolve()` 후 확인 |
| 정규식 | 분석 대상(최대 50MB 한 줄)에 돌리므로 되돌아가기 폭주를 피한다: 앞에 `[…]*`가 붙은 패턴(S01-GENERIC)은 키워드를 먼저 찾고 양옆으로 넓힌다. 결과는 명세와 같아야 한다 |
| 죽은 코드 | 남기지 않는다. 주석 처리한 코드도 지운다 (git에 남아 있다) |

## 4. 서버

### 4.1 계층
| 계층 | 할 일 | 하지 않을 일 |
|---|---|---|
| api | 입력 검증(계약 스키마), 서비스 호출, 응답 변환 | 계산, DB 직접 접근 |
| service | 흐름과 트랜잭션 경계, 예외 차례 | 판정 규칙 직접 구현 |
| engine | 순수 판정·계산. 입력·출력은 불변 dataclass(`contracts/engine.py`) | DB, 네트워크, `now()`, 전역 난수, 값 로그 |
| runner (REA만) | 다른 프로그램 실행, 시간 제한, 출력 받기 | 판정 |
| repo | ORM 조회·저장 | 비즈니스 판단 |

### 4.2 DB
- SQLite 파일 `<데이터 폴더>/selfaudit.db`. 모델은 `backend/app/db/models.py` 한 곳(공통).
- 스키마 변경은 마이그레이션으로만(`backend/migrations/versions/`, 서버가 시작할 때 `upgrade head`). 마이그레이션은 한 번에 한 태스크만 만든다(관제가 줄 세움). 레인은 요청한다.
- 데이터를 지우거나 형식을 바꾸는 마이그레이션은 커밋 설명에 영향과 되돌리는 방법을 적는다.
- 쿼리는 ORM 또는 바인드 파라미터로만. 비밀값 원문을 담는 칸을 만들지 않는다(D-014).

### 4.3 API
- 경로 `/api/v1/...`, 자원 이름은 복수형 명사. JSON 필드는 camelCase(`contracts/schemas.py`의 `ApiModel`).
- 오류 응답 형식 하나: `{"code": "VALIDATION_FAILED", "message": "사용자에게 보일 문장"}` (`core/errors.py`의 `AppError` 하위 클래스를 던진다). 스택·SQL·내부 경로·분석 대상 글·입력값은 넣지 않는다.
- 상태를 바꾸는 요청은 `X-SelfAudit-Client: 1` 머리말이 있어야 한다(NFR-08). 화면은 `src/api/client.ts`가 붙인다.
- zip 업로드는 multipart가 아니라 본문 그대로(`application/zip`, 이름은 `X-File-Name` 퍼센트 인코딩). multipart는 데이터 폴더 밖 임시 폴더에 쓰기 때문이다.
- 계약(`contracts/schemas.py`)을 바꾸면 `openapi.json`과 화면 타입(`npm run gen:api`)을 같이 다시 만든다. 검사 '계약'·'화면계약'이 잡는다. 계약 변경은 설계 몫이다.
- 화면에 필요한 계산(점수, 비교, 정렬)도 서버가 한다. 화면에서 다시 만들지 않는다.

### 4.4 다른 프로그램 실행 (REA만)
- `rea/runner.py` 한 곳. 절대 경로로, 셸 없이(`shell=False`, 인자 목록), 작업 폴더는 데이터 폴더, 시간 제한 필수(5초·120초), 넘으면 프로세스 트리째 끝낸다(Windows `taskkill /T /F`).
- 출력은 형식·값 범위를 검사한 뒤 내부 모델로 바꾼다(F-S05 4). 테스트는 가짜 실행기(고정 출력)로만.

### 4.5 오류·로그
- 도메인 오류는 `AppError`를 상속하고 `code`를 가진다. 예외를 조용히 삼키지 않는다.
- 점검 중 예외는 점검을 `실패`("점검 중 오류가 나서 멈췄습니다")로 바꾸고 로그에 점검 ID와 예외 종류만 남긴다.
- 로그에는 ID와 규칙ID·예외 종류만. 분석 대상의 글, 경로 안의 사용자 이름, 비밀값, 로컬 키는 남기지 않는다([보안규칙](보안규칙.md) 10장).

## 5. 화면

### 5.1 구조
| 폴더 | 내용 |
|---|---|
| `features/<영역>/` | 영역별 화면·데이터 훅(`api.ts`) (레인 경계) |
| `app/` | 경로표(`App.tsx`), 공통 틀(`Layout.tsx`), 디자인 토큰(`tokens.css`) (설계) |
| `components/` | 공통 구성 요소 (설계) |
| `api/` | `client.ts`(유일한 fetch), `schema.d.ts`(생성, 손으로 고치지 않음) |
| `lib/format.ts` | 날짜·점수·심각도 표시는 여기서만 |

### 5.2 규칙
- 서버 상태는 TanStack Query 훅으로만. 화면 안에 계산을 다시 구현하지 않는다.
- 스타일은 CSS Modules(`*.module.css`) + `tokens.css` 변수만. 색 코드를 직접 쓰지 않는다.
- 진짜 `<button>`, `<a href>`, `<label>`. 누르는 영역 44px 이상(`--touch-min`), 글자 대비 4.5:1 이상.
- 분석 대상에서 온 글(경로, 값, 근거 조각, REA 글)은 일반 텍스트로만 보인다. `dangerouslySetInnerHTML`·`innerHTML` 금지, `fetch`는 `api/client.ts`에서만(eslint가 잡음).
- 화면 문구는 화면정의 그대로. 뼈대의 `Pending`("준비 중: …")은 레인이 화면을 만들면 지운다.
- 화면을 만들면 1360·768·390px에서 확인한다(검증 세션).

| 종류 | 규칙 |
|---|---|
| 명세 예시 테스트 | 필수. 기능명세의 예시를 숫자 그대로 옮긴다. 예시가 없는 판정은 경계값 1~2개 |
| 분석 대상 | 테스트 안에서 만든 합성 파일(zip은 `zipfile`로 그 자리에서)만. 실제 비밀값 금지, 명세의 가상 값만 |
| 로컬 키 | 테스트 키 `selfaudit-test-key` (`tests/conftest.py`의 `TEST_KEY`) |
| REA | 가짜 실행기로 `사용함·없음·실패`를 모두. 실제 `rea`를 부르지 않는다 |
| 보안 기본 | `tests/core/test_security.py`(Host·Origin·머리말·보안 헤더·오류 응답 모양), `test_localkey_and_db.py`(로컬 키 노출). 뼈대에서 만들었고 유지한다 |
| 원문 노출 | 비밀값 규칙·내보내기 테스트는 응답·DB·내보내기 파일에 원문 문자열이 없는지 찾는다(NFR-03) |
| 이름 | `test_<기능ID>_<상황>` (예: `test_F_P01_예시_41자_거부`) |
| 언제 | 코드를 쓰는 동안은 지금 기능의 테스트만. 끝에 `check.py` 전체 한 번 |
| 기대값 | 통과시키려고 바꾸지 않는다. 예외는 `변경: CR-n` 태스크의 testStrategy에 적힌 테스트뿐 |
| 두지 않는 것 | 커버리지 기준, 화면 구성 요소 테스트(화면은 `lib/` 함수만 vitest). 버그가 반복되면 그때 더한다 |

## 7. Git과 작업 단위

- 기본 브랜치 `main`, main을 움직이는 것은 총괄뿐.
- 태스크 하나 = 브랜치 하나: `task/<id>-<짧은이름>`. 검증은 `verify/b<n>`.
- 하위 작업마다 커밋: `[T<id>.<n>] 한 줄 요약`. 변경 요청 태스크는 `(CR-n)`을 붙인다. 역할 커밋은 `[관제]`, `[문서]`, `[설계]`.
- 커밋은 내 파일만 경로를 적어서: `git commit -m "..." -- <파일들>`. `git add -A` 금지.
- 되돌리기: 하위 작업은 `git revert`, 태스크 전체는 브랜치를 병합하지 않는다. 기록을 지우는 명령(`reset --hard`, 강제 push)은 사용자 확인 후에만.

## 9. 도구 설정

**서버** — `backend/pyproject.toml` (실제 값은 그 파일이 기준)
- ruff: `line-length = 100`, 규칙 `E F W I B UP SIM RUF N S DTZ PLW1514 TID`, 무시 `RUF001~003`(한국어 문장 부호), `S101`, `N818`(오류 이름은 명세 용어). 금지 import(`TID251`): `pickle`, `requests`, `urllib.request`, `http.client`, `socket`.
- mypy `strict = true`.
- pytest: `--allow-hosts=127.0.0.1,::1`(pytest-socket, 외부 접속 차단). `-p no:cacheprovider`.
