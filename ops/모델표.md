# 모델·노력 표

주인: 총괄. 바꾸려면 사용자에게 묻고 이 표를 고친 뒤, 결정기록에 한 줄 남긴다.
모델 이름은 앱의 모델 목록에 있는 것을 쓴다 (지금: `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`).

## 지금 (2026-11-19, 사용자 결정 D-026)

**모든 세션과 에이전트를 Opus·높음으로 쓴다.**

| 누구 | 종류 | 모델 | 노력 | 어디에 적혀 있나 |
|---|---|---|---|---|
| 총괄 | 세션 | Opus | 높음 | 사용자가 앱에서 고른다 |
| 문서, 설계 | 세션 (필요할 때만) | Opus | 높음 | 총괄이 열 때 넣는다 |
| `lane-*`, `design`, `spec-editor` | 에이전트 | Opus | 높음 | `.claude/agents/*.md`의 `model`·`effort` |
| `security-reviewer`, `spec-checker`, `task-planner`, `doc-recorder` | 에이전트 | Opus | 높음 | 같음 |

## 규칙
1. 에이전트의 모델·노력은 정의 파일에 적혀 있어, 띄울 때 따로 넣지 않는다. 세션처럼 '연 뒤에 올리기'가 필요 없다.
2. **최대(max)는 쓰지 않는다.** 사용자가 직접 지시할 때만 쓴다.
3. **사용량**: 모두 Opus라 5시간 사용량이 빨리 찬다. 70%를 넘으면 레인을 1개로 줄이고, 90%를 넘으면 새 에이전트를 띄우지 않는다. 노력은 내리지 않는다(사용자 결정).
4. **기록**: 보드 '에이전트' 표와 `ops/측정.csv`에 태스크마다 반려·교대 횟수를 남긴다. 회고에서 이 표가 맞았는지 본다.
