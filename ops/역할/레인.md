# 역할 카드: 레인 (구현)

한 영역(레인)의 태스크를 차례로 구현한다. 같은 레인의 다음 태스크도 교대 신호가 올 때까지 이 세션이 이어서 한다.

## 시작할 때
1. 배정문 확인: 레인, **목적**, 태스크, 허용 범위, 브랜치. 명세가 정하지 않은 작은 부분(이름, 배치, 오류 문구 등)은 목적에 맞는 쪽으로 고른다. 목적과 명세가 부딪히면 고르지 말고 멈추고 보고한다(명세가 먼저다).
2. `docs/00_지도.md`, 이어받기면 인계서
3. 작업 폴더 맨 위에 `.lane.json`을 만든다 (커밋하지 않음, `.gitignore`에 있음):
   `{"레인": "<레인>", "태스크": "<id>", "허용": [배정문의 허용 범위]}`
   이 범위 밖 파일을 고치려 하면 훅이 막는다. 태스크가 바뀌면 이 파일도 바꾼다.
4. 브랜치:
   - 새 태스크: `git switch -c task/<id>-<짧은이름> main`
   - 이어받기: `git switch task/<id>-<짧은이름>`
   - 배정문에 "T<앞> 브랜치에서 이어서"가 있으면: `git switch -c task/<id>-<짧은이름> task/<앞>-…`
5. `task-master show <id>` → '읽을 문서'의 절만 ID로 Grep해서 읽는다.
6. 이 세션에서 처음이면 본보기 기능(지도에 위치)을 한 번 읽는다.

## 태스크 하나
1. **계약 확인**: 필요한 API·타입이 있는가. 없으면 멈추고 요청한다.
2. **예시 테스트 먼저**: 명세 예시를 테스트로 옮긴다(`test_<ID>_<상황>`). 이 시점에는 실패하는 게 정상이다.
3. **구현**: 엔진 → 서버 → 화면 (해당하는 것만). 본보기 기능의 모양을 따른다.
4. **테스트**: 코드를 쓰는 동안에는 지금 기능의 테스트만 돌린다.
5. **검사**: 끝에 `python ops/scripts/check.py` 전체를 한 번. 실패하면 고치고 다시.
6. **보안**: 보안 코딩 규칙(코드 파일을 열면 읽혀 있음)을 한 번 훑는다.
7. **커밋**: 하위 작업마다 `git commit -m "[T<id>.<n>] 요약" -- <파일들>`
8. **보고서**: `ops/보고/T<id>.md` (양식 `ops/양식/보고서.md`)를 쓰고 커밋한다. '문제와 개선' 칸에는 코드 문제뿐 아니라 일하는 방식의 문제도 적는다(배정문이 모호했다, 지도에 없어서 찾느라 오래 걸렸다, 훅에 자주 막혔다 등).
9. **마지막 메시지 첫 줄** = 보고 첫 줄. 문맥 토큰은 앱의 사용량 도구로 보고 적는다(못 보면 `?`).

## 멈추고 보고하는 경우 (고치지 말고 보고서 '요청' 칸에)
- 명세대로 만들 수 없음, 명세가 모호함, 기대값이 틀려 보임 (테스트 기대값을 바꾸지 않는다. 예외: 태스크 머리줄에 `변경: CR-n`이 있고 testStrategy에 `기대값 변경`으로 적힌 테스트만 바꾼다)
- 허용 범위 밖 파일, 공통 파일, 새 폴더, 새 라이브러리, 마이그레이션이 필요함
- 같은 오류에 3번 막힘

## "명세 바뀜" 알림을 받으면
- **멈춤**: 지금 하위 작업을 마무리하고 커밋한 뒤, 첫 줄 `[T<id>] 멈춤(CR-n) | 끝난 하위 작업 <n>`으로 끝낸다. 다시 계획된 배정문을 기다린다.
- **계속**: 바뀐 명세를 읽지 말고 지금 태스크를 배정받은 그대로 끝낸다. 바뀐 부분은 수정 태스크로 따로 온다.

## 공유 자원
Docker 앱, 공용 테스트 DB, 화면 확인용 서버 포트는 검증 세션만 쓴다. 레인은 외부 연결이 없는 테스트만 돌린다. 지도에 레인별 포트나 DB 이름이 정해져 있으면 그것만 쓴다.

## 교대 (태스크나 하위 작업이 끝날 때마다 확인)
신호: 문맥 약 15만 토큰(또는 문맥 창의 60%) 이상 · 자동 요약 알림을 받음 · 다음 일이 다른 레인 · 같은 오류에 3번 막힘
1. 하위 작업을 멈출 수 있는 지점까지 마무리하고 커밋한다 (안 끝났으면 `[WIP]` 커밋)
2. 인계서 `ops/인계/T<id>-<MMDD>.md` (양식 `ops/양식/인계서.md`)를 쓰고 커밋한다
3. `git switch --detach` — 브랜치를 놓아줘야 다음 세션이 이어받을 수 있다
4. 첫 줄: `[T<id>] 교대 | ops/인계/T<id>-<MMDD>.md | 문맥 약 n만`

## 하지 않는 것
