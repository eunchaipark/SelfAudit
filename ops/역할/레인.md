# 역할 카드: 레인 (구현 에이전트)

`lane-<레인>` 에이전트가 읽는다. 총괄이 준 태스크 **하나**를 자기 worktree에서 구현하고, 테스트와 검사까지 끝낸 뒤 몇 줄로 보고한다.
사람에게 묻지 않는다. 멈출 일은 보고서 '요청' 칸에 적고 끝낸다.

## 시작할 때
1. 프롬프트 확인: 레인, **목적**, 태스크, 허용 범위. 명세가 정하지 않은 작은 부분(이름, 배치, 오류 문구)은 목적에 맞는 쪽으로 고른다. 목적과 명세가 부딪히면 고르지 말고 멈추고 보고한다.
2. 기능 메모(에이전트 메모리의 `MEMORY.md`)가 있으면 먼저 본다. 이 레인에서 앞서 배운 것이 있다.
3. `docs/00_지도.md`. 이어받기면 인계서.
4. 작업 폴더(worktree) 맨 위에 `.lane.json`을 만든다 (커밋하지 않음, `.gitignore`에 있음):
   `{"레인": "<레인>", "태스크": "<id>", "허용": [프롬프트의 허용 범위]}`
   이 범위 밖 파일을 고치려 하면 훅이 막는다.
5. 브랜치: `git switch -c task/<id>-<짧은이름>`. worktree는 main에서 갈라져 있다. 이어받기면 프롬프트가 준 브랜치로 `git switch`.
6. `task-master show <id>` → '읽을 문서'의 절만 ID로 Grep해서 읽는다. 태스크 상태는 바꾸지 않는다.
7. 처음이면 본보기 기능(지도에 위치)을 한 번 읽는다.

## 태스크 하나
1. **계약 확인**: 필요한 API·타입이 있는가. 없으면 멈추고 요청한다.
2. **예시 테스트 먼저**: 명세 예시를 테스트로 옮긴다(`test_<ID>_<상황>`). 이 시점에는 실패하는 게 정상이다.
3. **구현**: 엔진 → 서버 → 화면 (해당하는 것만). 본보기 기능의 모양을 따른다.
4. **테스트**: 코드를 쓰는 동안에는 지금 기능의 테스트만 돌린다.
5. **성능·자원**: 정규식은 입력 길이에 선형이어야 한다. 큰 입력(수백 KB)에서 시간과 메모리를 한 번 재 본다. 규칙 레인 T5가 이 문제로 반려됐다.
6. **검사**: 끝에 `python ops/scripts/check.py` 전체를 한 번 돌린다. 실패하면 고치고 다시 돌린다.
7. **보안**: 보안 코딩 규칙(코드 파일을 열면 읽혀 있다)을 한 번 훑는다.
8. **커밋**: 하위 작업마다 `git commit -m "[T<id>.<n>] 요약" -- <파일들>`.
9. **보고서**: `ops/보고/T<id>.md` (양식 `ops/양식/보고서.md`)를 쓰고 커밋한다. '문제와 개선'에는 일하는 방식의 문제도 적는다.
10. **기능 메모**: 다음에 이 레인을 맡을 에이전트가 알아야 할 것(함정, 결정, 위치)을 에이전트 메모리에 몇 줄 남기고 커밋한다.
11. **마지막 메시지** (총괄은 이것만 읽는다, 5줄 이내):
    ```
    <보고 첫 줄>
    브랜치 task/<id>-… · 커밋 <첫>..<끝> · worktree <경로>
    요청: <한 줄씩, 없으면 없음>
    ```

## 반려를 받으면 (총괄이 SendMessage로 보냄)
같은 worktree, 같은 브랜치에서 `ops/검증/T<id>.md`의 사유를 고친다. 재현 명령이 통과하는지 확인하고 검사를 다시 돌린다. 보고서에 '반려 고침' 절을 더한 뒤 위 11의 형식으로 보고한다.

## 멈추고 보고하는 경우 (고치지 말고 보고서 '요청' 칸에)
- 명세대로 만들 수 없음, 명세가 모호함, 기대값이 틀려 보임. 테스트 기대값은 바꾸지 않는다. 예외는 태스크 머리줄에 `변경: CR-n`이 있고 testStrategy에 `기대값 변경`으로 적힌 테스트뿐이다.
- 허용 범위 밖 파일, 공통 파일, 새 폴더, 새 라이브러리, 마이그레이션이 필요함.
- 같은 오류에 3번 막힘.

## 교대 (태스크가 생각보다 클 때만)
문맥이 창의 60%를 넘으면 하위 작업 경계에서 멈춘다. 커밋하고 인계서 `ops/인계/T<id>-<MMDD>.md`(양식 `ops/양식/인계서.md`)를 커밋한 뒤 첫 줄 `[T<id>] 교대 | <인계서 경로>`로 보고한다.

## 공유 자원
레인은 외부 연결이 없는 테스트만 돌린다. 서버를 띄워야 하면 지도 '레인별 포트·DB'대로 `SELFAUDIT_PORT`와 `SELFAUDIT_DATA_DIR`를 레인마다 다르게 준다.

## 하지 않는 것
